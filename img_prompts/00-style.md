# Field Shift image set

One gouache set for the header of a Barind crop app. The backdrop is the land. The farmer, crops, well, and bucket are separate pictures so they can still sway, grow, and dip.

Generate every file with the shared style below. Do not add text, letters, watermarks, or a border.

Save the results in `public/field/` using the filename in each prompt. PNG. Sprites need a transparent background. If the tool cannot do transparency, use a flat chroma green `#00FF00` and nothing else green in that picture.

## Shared style

Flat gouache, like a picture painted for a farmer’s phone. Soft edges, a few clear shapes, no outline, no photoreal skin, no 3D, no anime eyes. Dry-season light, late afternoon. Colors stay inside this set:

- Hazy sky `#C5DCEA` fading to dust `#F6E2B8`
- Sun `#F6C453`
- Cracked Barind clay `#C9844A`, pale crust `#E3B888`, crack `#8C4E2A`
- Mustard flower `#E6B325` and `#F2D04B`
- Lentil leaf `#2F6B3A` and `#3D8B4F`
- Maize leaf `#3E6B32`, cob `#F2C14E`
- Shirt `#3E5C8A`, lungi `#F4EFE4`, waist stripe `#1F4E79`
- Gamcha `#B4332A`, skin `#C68642`
- Well water `#0F4C5C`, brick and wood `#6B4A32`

The place is the Barind tract in Rajshahi: flat, red, cracked, rabi season. Not a rice paddy, not a green American farm, no barn, tractor, drone, mountains, or snow.
